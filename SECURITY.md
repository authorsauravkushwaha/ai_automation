# Security policy

HINATA is alpha software and has not received an independent security audit.
Read the [security model and limitations](docs/SECURITY.md) before using it with
sensitive data. Normal startup does not block network access; see the
[offline isolation guide](docs/OFFLINE_ISOLATION.md).

## Reporting a vulnerability

If GitHub's private vulnerability reporting is enabled for this repository, use
**Security → Advisories → Report a vulnerability**. Include affected version or
commit, a minimal reproduction, potential impact, and any suggested mitigation.
Please do not include credentials, private files, recordings, or unnecessary
personal information.

If private reporting is not available, open an issue asking a maintainer for a
private reporting channel **without disclosing exploit details**. Please allow
maintainers time to investigate before public disclosure. No response or fix
schedule is guaranteed.
